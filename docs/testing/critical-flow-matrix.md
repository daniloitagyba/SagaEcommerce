## Quality policy

- The coverage floor remains at the measured repository baseline until a new
  report proves a sustainable increase; generated code and DI wiring are not
  counted as substitutes for branch coverage in domain behavior.
- Mutation testing targets branching business rules. A surviving mutant must
  result in a focused test or a documented, expiring exception.
- A flaky critical-flow test is a defect. It is not placed behind an unlimited
  retry or removed from a required job.
